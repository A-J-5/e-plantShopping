# e-plantShopping

e-plantShopping is a React-based plant shopping application that allows users to browse different categories of plants, view plant details, add products to a shopping cart, update item quantities, remove items, and view the total cart amount.

The application uses Redux for cart state management, allowing cart items and quantities to update across components in real time.

## Project Features

- Displays plants by category
- Shows plant name, image, description, and cost
- Allows users to add plants to the cart
- Disables the Add to Cart button after a product is added
- Calculates item subtotal and total cart amount
- Allows users to increase, decrease, and remove cart items
- Uses Redux Toolkit for state management
